## 🤖 AI Career Copilot

An AI-powered career intelligence platform built with **Java and Spring Boot** that turns a resume into an interactive career assistant.

The application helps candidates analyze their resumes, ask questions about resume content, compare resumes with job descriptions, identify skill gaps, practice technical interviews, and generate personalized career roadmaps.

### 🛠️ Technologies

- Java
- Spring Boot
- Spring AI
- Generative AI
- LLM
- Prompt Engineering
- Retrieval-Augmented Generation (RAG)
- Embeddings
- Vector Search
- Ollama
- Llama 3.2
- Nomic Embed Text
- PostgreSQL
- PGVector
- Spring Data JPA
- Hibernate
- Docker
- HTML
- CSS
- JavaScript

### ✨ Features

- 📄 Resume PDF ingestion and processing
- 💬 RAG-powered Resume Chat
- 📊 Resume Analyzer
- 🎯 Job Description Matcher
- 🧠 Skill Gap Analyzer
- 🎤 Technical Interview Practice & Evaluation
- 🗺️ Personalized 90-Day Career Roadmap
- 🔒 Local AI inference using Ollama

### 🧠 AI Workflow

**PDF Resume → Text Extraction → Chunking → Embeddings → PGVector → Vector Retrieval → Ollama LLM → Grounded Response**
